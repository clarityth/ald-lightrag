# 문헌 비교 작업의 저장과 근거 선택

## 사용자 작업

질문으로 문헌을 찾고 실험 조건과 측정 원문을 확인한다. 비교할 측정값을 선택하고 CSV로 저장한다. 새로고침 후에도 마지막 작업을 다시 연다.

## 동작

- 검색된 측정 자체와 실험 정의에서 간접 연결된 측정을 구분한다. 선택 한도 안에서 문헌별 후보를 순환한다. 각 문헌 안에서는 질문 관련성과 직접 검색 여부로 정렬한다. 검색된 원문 문단은 별도로 유지한다. 질문별 문자열이나 정답 ID를 사용하지 않는다. 질문 개념이 없다는 이유로 검색 원문을 폐기하지 않는다.
- 마지막으로 작업한 성공 결과와 선택한 행을 이 브라우저에 저장한다. 새로고침 후 복원한다. 저장 실패는 사용자에게 알리며 현재 결과와 CSV 기능은 유지한다. 저장된 작업을 지우는 기능을 제공한다.
- 원문과 CSV는 기존 연결 및 형식을 재사용한다. CSV에는 근거 발췌와 문단 ID 및 전체 문단을 함께 저장한다. 조건과 결과의 원문을 따로 확인할 수 있어야 한다. 자동 번역과 추가 보고서 생성은 포함하지 않는다.
- 실패한 새 질문이 마지막 성공 결과를 덮어쓰지 않는다. 다른 질문의 선택 상태가 섞이지 않는다.

## 확인

선택 순서와 저장 상태의 결정적 로직은 실패 테스트를 먼저 작성한다. 실제 새 질문을 실행하고 원문 확인, 행 선택, 새로고침, CSV 다운로드를 확인한다. 독립 검토자는 구현과 실제 원문 연결을 대조한다. 모델 답변의 성능 우위를 이번 기능의 완료 조건으로 사용하지 않는다.

## 범위

기존 12편과 기존 모델을 사용한다. 문헌 수집, 신규 모델, 평가 반복, 계정 기능은 추가하지 않는다. 질문과 저장 자료는 현재 브라우저에만 보관하며 공개 저장소에 올리지 않는다.
