# 실험 조건과 측정 결과 비교

## 사용자 문제
답변에서 여러 논문의 실험을 비교하려면 인용을 하나씩 열고 조건을 기억해야 한다. 같은 화면에서 실제 인용된 측정 결과와 실험 조건을 확인해야 한다.

## 동작
답변 아래에 실험 비교표를 펼칠 수 있게 한다. 각 행은 실제 인용된 측정 기록 하나이며 문헌, 시료, 변경·고정 공정 조건, 측정 지표, 값·단위, 측정 조건과 원문 버튼을 제공한다. 동일 측정 ID는 한 번 표시한다. 원문 버튼은 기존 근거 패널을 연다.

문단에 여러 측정이 있는 일반 인용은 어떤 값을 답변이 사용했는지 확정할 수 없으므로 비교표의 자동 행으로 만들지 않는다. 측정 ID가 연결된 인용만 표에 포함한다. 일반 인용은 기존 원문 패널에서 확인한다.

## 완료 조건
- 서로 다른 두 실험군의 값과 조건이 섞이지 않는다.
- 답변이 인용하지 않은 측정은 표에 추가하지 않는다.
- 표에서 해당 측정의 원문을 연다.
- 연결된 측정이 없으면 빈 표를 만들지 않는다.
- 모바일에서 가로 스크롤로 열을 확인할 수 있다.

## 범위
기존 검색·생성·색인과 데이터는 변경하지 않는다. 추가 모델 호출, 질문별 규칙, 단위 변환 및 성능 순위는 만들지 않는다.
