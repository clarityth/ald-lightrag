# 実験条件比較 / 실험 조건 비교 작업

## 사용자 업무
질문으로 찾은 실험의 공정 조건과 측정 결과를 비교하고, 필요한 행과 원문을 검토 자료로 저장한다.

## 범위
- 새 답변과 저장된 예시에 같은 비교 기능을 제공한다.
- 최종 검색 문맥에 연결된 측정 기록을 표시한다. 답변이 인용한 기록만으로 제한하지 않으며, 검색된 기록을 모두 답변의 주장으로 표현하지 않는다.
- 문헌, 시료, 변경 조건, 고정 공정 조건, 측정 지표, 값/단위, 측정 조건을 구분한다. 누락 값은 '정보 없음'으로 표시하고 비교 가능성이나 인과관계를 임의 판정하지 않는다.
- 사용자가 측정 행을 선택/해제하고 선택한 행을 CSV로 내려받는다. 질문, 실험 조건, 측정 결과, 문헌 URL, 조건 및 측정의 원문 발췌를 포함한다. CSV 수식 실행을 방지하고 따옴표/개행/한글을 보존한다.
- 조건과 측정 원문은 각각 해당 문단으로 연다. 서로 다른 문헌의 동일 로컬 ID를 혼합하지 않는다. 원문이 없는 경우 링크를 만들지 않는다.
- 화면에는 비교표를 먼저 제공하고 상세 그래프 경로는 보조 기능으로 둔다. 키보드와 좁은 화면에서도 선택/내보내기/원문 열기가 가능해야 한다.

## 검증
결정적 데이터 연결과 CSV 처리는 실패 테스트를 먼저 작성한다. 기존 테스트 및 실제 브라우저에서 저장된 답변 → 행 선택 → 원문 → 다운로드 흐름을 확인한다. 독립 리뷰와 CI 후 병합한다.

## 성과 해석
현재 비교의 문맥 예산 차이를 그래프만의 효과로 해석하지 않는다. 사용자 작업 시간은 실제 사용자 시험 전에는 성과로 기록하지 않는다. 이번 구현에는 신규 추출/생성 호출이 필요하지 않으며, 기존 결과의 정보만 사용한다. 검색 품질과 동일 예산 비교는 별도 검증 항목으로 구분한다.
