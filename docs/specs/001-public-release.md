# 공개 실행본

## 사용자 문제
ALD 문헌의 수치를 비교할 때 증착, 열처리, 측정 조건과 시료 구조를 함께 확인해야 한다. 답변의 수치에서 해당 실험 조건과 원문으로 이동할 수 있어야 한다.

## 기능과 완료 조건
- 문헌 12편의 출처 및 이용 조건을 제공한다.
- 질문으로 LightRAG mix 검색을 실행하고 원문과 연결된 실험군·측정 결과로 답변한다.
- 인용을 누르면 시료, 변경 조건, 고정 조건, 측정값, 측정 조건과 원문이 표시된다.
- 인증정보는 환경변수로 전달한다. 개인 경로나 로컬 비밀 파일에 의존하지 않는다.
- 최초 실행은 의존성 설치 → API 설정 → 색인 → 서버 실행 순서로 재현한다.
- 네트워크 없는 회귀 테스트와 공개 파일 검사를 CI에서 실행한다. 실제 모델의 답변 정확성은 별도 원문 대조로 확인한다.

## 공개 범위
소스, 회귀 테스트, 이용 조건을 확인한 문헌 발췌, 실행 안내 및 개발 규칙을 포함한다. 원문은 문단 추출·재구성한 자료임을 명시한다. 내부 대화, 운영 메모, 개인 경로, 인증정보, 런타임 색인과 호출 로그는 배포하지 않는다.

## 평가 범위
이전 두 질문의 동일 근거 비교에서 답변 모델 변경 후 수치와 조건의 귀속을 확인했다. 전체 질문 정확도나 다른 검색 방식에 대한 우위를 뜻하지 않는다. 기존 구현의 공개 전환이며 기존 개발 이력을 재작성하지 않는다.
