# 개념 그래프의 근거 선택

## 문제와 목적
현재 mix 검색의 청크로 논문을 선택한 뒤 해당 문헌 전체와 모든 측정을 답변에 넣는다. 그래프의 개체와 관계를 근거 선택에 사용하도록 변경하고 동일 데이터에서 비교한다.

## 구현 계약
- 공개 정규화 사전의 정식 이름/별칭으로 재료, 기판/구조, 변경 공정 변수, 측정 지표를 매핑한다. 미분류를 집계하며 이름 유사도나 질문별 예외로 채우지 않는다.
- 실험군→재료/기판/구조/변경 변수, 측정→지표의 개념 간선을 custom KG에 추가한다.
- 그래프 방식은 질문 개념과 LightRAG aquery_data의 entities/relationships를 사용하여 실험군·측정·근거를 선택한다. 선택된 측정, 실험군 정의와 인용 원문만 문맥에 넣는다. 선택 경로를 응답으로 반환한다.
- 기존 검색 문헌 전체 확장은 full_documents 옵션으로 보존한다. 평가 all 방식은 12편 전체, naive 방식은 상위 10문단, graph 방식은 선택 근거를 사용한다.
- 세 평가 방식은 동일한 답변 모델, 프롬프트, 출력 상한을 사용한다. 그래프 개념 사전에서 얻은 검색 키워드를 직접 넘겨 LightRAG 검색 중 생성 호출을 하지 않는다. 질문당 최종 생성은 한 번이며 자동 재시도는 없다.
- 경로 화면은 개념 → 문헌/실험군 → 측정 → 원문을 표시한다. 측정 클릭은 기존 원문 패널을 연다.

## 평가
실행 전에 단일·다문헌 질문 총 15개와 필수 측정 및 원문 인용을 커밋한다. 이후 질문과 정답은 고정한다. 실행은 15×3=45번의 최종 생성 호출로 제한한다. 임베딩 호출은 별도로 계수한다. 실패도 결과로 보존하고 추가 생성으로 덮지 않는다.

측정 회수율은 필수 측정의 근거 원문이 최종 문맥에 포함됐는지로 계산한다(구조화 레코드 유무로 naive에 불이익을 주지 않는다). 답변 수치·인용 일치율은 생성 답변의 실제 수치 주장과 연결 원문을 대조하며 판단 불가를 분리한다. 문맥 토큰, 전체 질의 시간, API usage와 확인 가능한 단가에 따른 비용을 공개한다. 단가 확인 불가 시 금액을 만들어 쓰지 않는다.

## 완료와 범위
개념 수/다문헌 개념 수/매핑률/미분류, 3방식×5지표, 경로 화면, CI와 독립 검토 결과를 공개한다. 내부 호출 로그·키는 제외한다. 120편 확대는 승인 전 수행하지 않는다. 기존 개선 주장은 공개 근거를 연결하거나 삭제한다.
