# 독립 평가 질문 007

이 질문 12개는 `data/experiments.json`의 실험·측정 기록과 `mechanism_poc/sources/dataset.json`의 문헌 문단을 기준으로 작성했습니다. 기존 `evaluation/questions.json`의 15개와 질문 초점과 필수 측정값의 조합을 대조했습니다. 검색 구현이나 답변 결과는 보지 않았습니다.

단일 문헌 질문 6개(H01–H06)는 측정 온도, 스윕 전압, XPS 성분, 증착 온도, 시료 두께, 산소 전구체를 각각 다룹니다. 다문헌 질문 6개(H07–H12)는 같은 재료라도 막 두께·소자 구조·지표·측정 조건이 달라 결과를 혼합하기 쉬운 상황을 다룹니다. H04와 H05는 단순한 사실 조회도 포함하며, H08과 H11은 단위가 같은 전압 또는 다른 전류 단위가 뜻하는 측정 지표를 구분하도록 합니다.

| 질문 | 문헌 ID | 주요 구분 대상 |
| --- | --- | --- |
| H01 | PMC10005305 | HZO 측정 온도와 증착 온도, P–E와 피로 수명 |

`required_measurements`에는 각 실험 기록의 ID, 값, 단위를 그대로 옮기고 문헌 문단에 포함된 인용문을 넣었습니다. 이는 답변의 근거 요구사항이며, 질문 본문에는 정답 수치를 넣지 않았습니다.
