# 고정 문헌 질문과 필수 원문 근거

`questions.json`은 12편의 공개 문헌을 대상으로 평가 실행 전에 확정한 질문 15개입니다. 단일 문헌 질문 7개와 다문헌 질문 8개로 구성했습니다. 단순한 수치 확인, 동일 논문 안의 조건 비교, 논문 간 같은 지표 비교, 목적과 측정 방법이 다른 연구의 구분을 함께 평가합니다. `Q08`은 공개 데모의 질문 문장과 정확히 같습니다.

각 질문의 `kind`는 `single_paper` 또는 `multiple_papers`입니다. `required_measurements`의 각 항목은 측정 ID, 문헌 ID, 원문 문단 ID, 문단에서 그대로 인용한 연속 문자열, 추출된 값과 단위를 담습니다. 필수 항목은 질문당 2~4개이며 총 55개입니다. 원문 인용은 [문헌 데이터](../mechanism_poc/sources/dataset.json)의 해당 문단에서, 값과 단위는 [실험 기록](../lightrag_app/storage-experiments-v3/experiments.json)의 동일 측정 ID에서 가져왔습니다. 실험군, 시료, 측정 조건의 해석은 실험 기록의 `experiment_id`와 `conditions`를 따라야 합니다.

비교 시 필수 측정의 인용문이 최종 문맥에 있는지 확인합니다. 측정 레코드의 구조가 없어도 원문이 포함되어 있다면 근거를 회수한 것으로 봅니다. 한 원문에 여러 값이 적힌 경우에는 `value`와 `unit`만으로 실험군을 추정하지 않고 질문, 원문 문맥, 실험 기록의 조건을 함께 대조합니다. 문헌마다 시료와 시험 목적이 다른 결과를 하나의 성능 순위로 합치지 않습니다. `Q08`의 HfO2 논문은 짧은 퍼지에서 성장량 증가와 조성 변화를 수치로 기록하지만, 해당 퍼지 조건별 유전율의 수치는 보고하지 않습니다. 따라서 유전율 변화를 수치로 만들어 답해서는 안 됩니다.

고정에 사용한 파일의 SHA-256은 다음과 같습니다.

- `mechanism_poc/sources/dataset.json`: `71f65945d5df88f582d0c67db1ab761addcb1160dd8fe9755d6a628da4d305f8`
- `lightrag_app/storage-experiments-v3/experiments.json`: `bfe836f138250ec60b50724b3114d52c7af0244d1ed88fa52683b5c8d4f07274`

평가를 실행한 뒤에는 질문 문장과 필수 근거를 수정하지 않습니다. 원문이나 추출 기록이 바뀌면 기존 결과와 섞지 않고 별도 평가 버전을 만들어 비교합니다.
