# 고정 평가 프로토콜

- 질문: evaluation/questions.json, 15개(단일 문헌 7개, 다문헌 8개), 필수 측정 55개. 평가 전에 커밋했으며 실행 후 변경하지 않는다.
- 데이터: 12편 309문단과 data/experiments.json의 93개 실험군·291개 측정. 수집·추출을 다시 실행하지 않는다.
- all: 12편 원문 전체(84,583 context tokens).
- naive: LightRAG naive의 상위 10문단. SDK 문맥 상한 30,000.
- graph: SDK mix 반환 개체·관계에 등장한 질문 개념을 출발점으로 저장된 개념 간선을 따라 다른 문헌의 실험군·측정까지 확장한다. 질문에서 확인된 범주별 개념을 만족하는 측정을 문헌별로 번갈아 최대 32개 선택한다. 선택된 측정·실험 정의·근거 문단만 최대 16,000토큰에 넣는다. 미분류 개념은 추정하지 않는다.
- 기존 검색 문헌 전체 확장은 full_documents 옵션으로 보존하고 이번 3방식 평가에는 사용하지 않는다.
- 공통 답변 모델: gpt-6-sol, reasoning low, 최대 출력 1,800토큰, 동일 중립적 인용 프롬프트. 질문당 생성 1회, 총 45회 상한. 재시도 없음. 방식 순서를 질문마다 회전한다.
- 질의 중 키워드는 사전에서 결정적으로 추출하고 SDK에 전달하므로 추가 생성 호출은 없다. 임베딩은 별도 계수한다.

## 지표

필수 측정 회수율은 해당 측정의 모든 필수 근거 문단이 최종 문맥에 들어갔는지로 계산한다. 구조화 측정 ID 존재를 요구하지 않으므로 raw 문단을 사용하는 두 기준 방식도 같은 기준이다. 이는 근거 접근 가능성이지 생성 답변의 정답률이 아니다.

답변 수치·인용 일치율은 생성된 수치 주장을 인용 문단과 직접 대조한다. 조건 수치와 결과 수치를 구분하고, 원문에 같은 숫자가 있다는 이유만으로 정답 처리하지 않는다. 검토 불가·무수치 답변은 분리한다. 지표는 원문 대조 표를 함께 공개한다.

문맥 토큰은 동일 tokenizer로 계산한다. 응답시간은 검색부터 최종 생성까지 측정하며 단발 실행의 관측값이다. 비용은 API 사용량의 일반/캐시 입력과 출력, 질의 임베딩을 합산한 추정치다. 색인 구축과 사전 추출 비용은 질의 비용에 포함하지 않는다.

## 실행 전 비용 예상

공식 Standard 요금: gpt-6-sol 1M 토큰당 입력 $2.00, 캐시 입력 $0.20, 출력 $10.00. text-embedding-3-small 입력 $0.02/1M. 확인일 2026-10-25.

- all 85K, naive 최대 30K, graph 최대 16K 입력을 각 15회로 잡으면 입력 약 $3.93.
- 출력 상한 1,800×45는 $0.81. 프롬프트 및 질의 임베딩 여유를 포함한 예상 약 $4.85(캐시 할인 전).
- 이는 예상이며 실측 사용량 기반 금액을 최종 표에 기록한다. 세금과 계정 청구서 할인은 반영하지 않는다.
